# Наследие — летняя версия

Сайт подготовлен для GitHub Pages.

В форме используется Telegram-отправка. Для безопасности токен бота не хранится в открытом index.html.
Подключите Telegram Bot API через серверный обработчик (Cloudflare Worker / Vercel Function), указав:
- BOT_TOKEN
- CHAT_ID (-1003555326739)
